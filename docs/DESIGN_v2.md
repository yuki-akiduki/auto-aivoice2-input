# AIVoice2 テキスト自動入力 — v2 追加機能設計

## 変更概要

### 名称変更
- 「キャラクター検証」→「キャラボイス設定」
- 「台本プレビュー」→「ボイスプレビュー」

### 機能追加

#### 1. スキップ機能
- キャラボイス設定のプルダウンに「⏭ スキップ」選択肢を追加
- VPCXに存在しないキャラ（例: 六花）や、音声出力不要な行をスキップ
- スキップされた行はボイスプレビューでグレーアウト表示
- 自動入力時にスキップ行は処理しない

#### 2. ボイスプレビューにマッピング後のキャラ名表示
- 台本の元キャラ名（葵）ではなく、マッピング後のキャラ名（葵_普通）を表示
- 列構成: #, 元キャラ, → , 割当ボイス, セリフ
- マッピング変更時にリアルタイム更新

#### 3. ボイスプレビューの更新機能
- キャラボイス設定を変更したら、ボイスプレビューが自動更新される
- 「更新」ボタンも設置（手動更新用）

#### 4. 行単位のボイス変更機能
- ボイスプレビューの各行で、割当ボイスをクリックするとプルダウンが表示
- そのキャラのボイスバリエーション一覧から選択できる
  - 例: あかり_普通 → あかり_喜び、あかり_悲しみ、あかり_怒り
- 変更した行は色で区別表示（個別変更済み）

## データフロー

1. 台本読み込み → parse_script → [{character, text}, ...]
2. VPCX読み込み → load_vpcx → [キャラ名一覧]
3. マッチング → match_characters → {exact, partial, unmatched, auto_mapping}
4. ユーザーがマッピング調整（スキップ含む）
5. ボイスプレビュー自動更新（各行に resolved_voice を計算）
6. ユーザーが行単位で個別変更（overrides に保存）
7. 開始 → mapping + overrides を合わせて実行

## 実装変更箇所

- プルダウンに「⏭ スキップ」追加

- 行単位のボイスバリエーションプルダウン
- スキップ行のグレーアウト

### gui.py
- `start()` に overrides 引数追加
