# A.I.VOICE2 テキスト自動入力ツール

AIVoice2 Editor に台本ファイルからテキストとキャラクター設定を自動入力するデスクトップツール。

## 機能

- 台本ファイル（テキスト）を読み込んで、AIVoice2 に1行ずつ自動入力
- VPCXファイルからキャラクター情報を読み込み、台本のキャラ名と自動マッチング
- キャリブレーション機能（UIの位置をユーザーが記録）
- 行単位のボイスバリエーション変更、スキップ設定
- ESCキーで緊急停止、途中再開対応

## 必要環境

- Windows 10/11
- Python 3.10+
- A.I.VOICE2 Editor（エーアイ社）

## インストール

```bash
pip install pyautogui pyperclip pywebview pywin32 pythonnet Pillow
```

## 起動方法

### GUI（通常）

```bash
python -m auto_aivoice2
```

または `start.vbs` をダブルクリック（コンソール窓なしで起動）。

### CLI（シンプル版）

```bash
python run_automation.py 台本ファイル.txt
```

※ CLI版はキャリブレーション・キャラマッピング非対応

## 使い方

### 1. 準備

1. AIVoice2 Editor を起動し、新規プロジェクトを開く
2. AIVoice2のキャラクター設定から `.vpcx` ファイルをエクスポートしておく
3. 台本ファイルを用意する（後述のフォーマット）

### 2. ファイル読み込み

1. ツールを起動する
2. 「台本ファイル」の「参照...」から台本テキストファイルを選択
3. 「VPCXファイル」の「参照...」からエクスポートした `.vpcx` ファイルを選択
4. キャラクターの自動マッチング結果が表示される
   - 緑タグ: 完全一致
   - オレンジタグ: 候補あり（ドロップダウンで選択）
   - 赤タグ: 不一致（手動で割り当てるかスキップ）

### 3. キャリブレーション（初回のみ）

AIVoice2のUI位置を記録します。

1. 画面下部の「キャリブレーション」セクションで各ステップの「記録」ボタンをクリック
2. 5秒以内にAIVoice2の指示された場所にマウスを移動
3. 4箇所を記録:
   - ① 検索ボックス
   - ② 検索結果の1番目のキャラ
   - ③ 「+」追加ボタン
   - ④ 1番目のテキスト入力エリア

※ AIVoice2のウィンドウ位置やサイズを変えた場合は再キャリブレーションが必要

### 4. 自動入力の実行

1. 「ボイスプレビュー」で割り当てを確認（行単位で変更可能）
2. 「開始」ボタンをクリック
3. 3秒のカウントダウン後、自動入力が開始
4. 実行中は予想時間と経過時間が表示される
5. 完了後、ログが一括表示される

### 5. 停止・再開

- **停止**: 「停止」ボタンまたは ESCキー
- **途中再開**: 停止後に「途中再開」ボタンで中断した行から再開

## 台本ファイルのフォーマット

```
キャラ名：セリフ
キャラ名：セリフ
```

- 区切り: 全角コロン `：` または半角コロン `:`
- 空行と `#` で始まる行はスキップ
- キャラ名はVPCXのキャラ名と完全一致、または前方一致でマッピング

### 例

```
葵：皆さん、こんにちは！今日の動画を始めましょう。
茜：こんにちは！今日もよろしくお願いします！
詞音：こんにちは。今日のテーマは何ですか？
ゆかり：今日はプログラミングについて話しましょう。
あかり：わぁ、楽しそうですね！
```

## 注意事項

- 自動入力中はマウスやキーボードに触れないでください
- AIVoice2のウィンドウが他のウィンドウに隠れないようにしてください
- 緊急停止はマウスを画面左上隅に移動（pyautogui のフェイルセーフ）
